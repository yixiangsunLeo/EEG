# ATCNet 归因 · 域对抗调研 · 第一性原理分析

> 对应学长交代的任务 1（ATCNet 为什么强）、任务 3（最新域对抗方法）、任务 4（第一性原理）。
> 数字全部来自 `docs/RESULTS_TRUTH.md`（从原始 `result.json` 重算）。

## 摘要

1. ATCNet 的强不在容量而在**结构性正则**：它的分类头只有 **495 个参数**，S4ERP 是 **187,000**，差 378 倍；再叠加 5 个滑窗的内置集成。
2. **但 ATCNet 的优势只出现在本来就好解码的被试上**（与被试易度相关 r = +0.53），在两个最难的被试上优势恰好为 0。
3. 域泛化文献的共识是**调好的 ERM 很难被打败**；更关键的是 2025 年的理论工作指出：invariance 类方法（DANN/IRM/CORAL）只在 **covariate shift** 下正确，在 **posterior drift** 下应该反过来做 **domain-informed**。
4. 我们的数据强烈提示 EEG 跨被试含有大量 posterior drift 成分，这与 ATCNet-Adv 初步 **−7pp** 的负结果一致。
5. **主要瓶颈不是模型**：被试间极差 50.1pp，模型间只有 6.2pp，比值 45 倍。只修好 sub-011 一个人（+3.00pp）就超过所有模型选择空间的一半。

## 1. 任务 1：ATCNet 为什么强

### 1.1 参数分解

总计 114,719（58ch / 1000pt / 3 类）：

| 组件 | 参数 | 占比 | 说明 |
|:---|---:|---:|:---|
| ConvBlock（时空滤波） | 19,424 | 16.9% | EEGNet 式时域卷积 + 深度可分离空间卷积 → `[B, 32, 17]` |
| MHA × 5 | 10,960 | 9.6% | 2 头，key_dim 8，作用在长度 13 的窗口上 |
| TCN × 5 | 83,840 | 73.1% | 每窗口独立的因果空洞卷积 |
| **分类头 × 5** | **495** | **0.4%** | 5 个 `Linear(32, 3)`，logits 平均 |

结构：`Tc=17`（卷积后时间步），切成 `n_windows=5` 个长度 `Tw=13` 的重叠窗口（重叠率 71%），每窗口独立过 MHA + TCN + dense，最后**平均 logits**。

### 1.2 假设 H1（最强）：微型分类头

| 模型 | 进入分类器的特征维 | 分类头参数 | 过拟合 gap | Acc |
|:---|---:|---:|---:|---:|
| ATCNet | 32（每窗口） | **495** | +22.1pp | 70.85% |
| S4ERP | 62,336 | **187,000** | +32.7pp | 64.68% |

训练集每折只有 **7,199** 个 trial。S4ERP 的分类头参数量是样本量的 **26 倍**，输入特征维是样本量的 **8.7 倍**——在这个 p ≫ n 的区间，过拟合是结构性的，不是调参能解决的。ATCNet 的 495 个参数则完全在安全区。

这条假设已被 §1.5 的过拟合表间接支持（EEGNet 3.5K 参数 gap 最小 +14.7pp，S4ERP 最大 +32.7pp），但**参数量和 gap 的相关性不是单调的**（66.9M 的 DualCD-Flatten gap +27.3pp 反而好于 1.6M 的 EEG-Deformer +27.7pp），所以真正起作用的是**分类头的宽度**而非总参数量。

### 1.3 假设 H2：滑窗集成

5 个窗口各有独立的 TCN 和 dense 头，最终平均 logits。这在数学上就是 **5 模型集成**，而集成的主要收益是**方差抑制**——恰好对 EEG 这种低信噪比数据最有价值。

**可验证**：`n_windows=1` 消融。如果集成是主力，单窗口应该掉 3-5pp。

### 1.4 假设 H3：MHA 可能是摆设

只有 10,960 个参数（9.6%），2 个头、key_dim 8，作用在长度 13 的序列上。容量极小，位置在 TCN 之前。

**可验证**：`attention=None` 消融。我预测掉点 < 1pp。

### 1.5 假设 H4：深度可分离空间卷积 ≈ CSP

ConvBlock 的第二层是跨全部 58 通道的深度可分离卷积，功能上等价于学习一组空间滤波器——这正是 MI 解码的经典先验（CSP）。S4 的全局状态空间没有这个归纳偏置。

### 1.6 一个反直觉的观察：ATCNet 收敛最慢

| 模型 | 我们的配方 best epoch | 论文配方 best epoch |
|:---|---:|---:|
| ATCNet | 44.8 / 100 | **297.6 / 374** |
| EEGNet | 39.7 | 303.6 |
| S4ERP | 14.5 | 34.0 |
| DualCD-Flatten | 3.7 | 7.7 |

**ATCNet 在我们的 100-epoch 上限下是被截断的**（论文配方下它要跑到第 298 个 epoch）。这是小分类头的代价：容量小 → 拟合慢 → 需要长训练。

**这条直接解释了 ATCNet-Adv 的负结果**：我把 λ 的 ramp 设成"第 50 epoch 到满"，是照搬 S4ERP-Adv 的调度。但 S4ERP 在第 15 个 epoch 就选出最优模型，那时 λ 才 0.22——**它几乎是在无对抗的条件下训练的**；ATCNet 的最优点在第 45 个 epoch，λ 已经 0.89。两者名义上"同一套调度"，实际承受的对抗压力差了 **4 倍**。这不是公平对照。

### 1.7 关键限制：ATCNet 的优势只在好被试上

| 被试（按难度） | 他人均值 | ATCNet | 优势 |
|:---|---:|---:|---:|
| sub-011 | 37.0% | 37.0% | **−0.0pp** |
| sub-006 | 56.6% | 56.4% | **−0.1pp** |
| sub-004 | 61.1% | 65.7% | +4.5pp |
| sub-001 | 61.3% | 66.0% | +4.7pp |
| sub-008 | 67.9% | 73.8% | +5.8pp |
| sub-005 | 68.0% | 68.3% | +0.3pp |
| sub-009 | 71.6% | 73.8% | +2.2pp |
| sub-010 | 73.1% | 76.6% | +3.5pp |
| sub-003 | 76.0% | 81.7% | +5.7pp |
| sub-002 | 80.1% | 90.4% | **+10.4pp** |
| sub-007 | 86.6% | 89.6% | +2.9pp |

优势与被试易度的相关 **r = +0.53**。ATCNet **更善于榨取本来就存在的信号，而不是从难被试身上挖出信号**。这个性质会传给任何以它为骨干的改进。

## 2. 任务 3：域对抗方法调研

### 2.1 首先是一盆冷水：ERM 很难打

- **DomainBed**（Gulrajani & Lopez-Paz 2021）："no algorithm included in DomainBed outperforms ERM by more than 1%."
- **ERM++**（Teterwak et al. 2025）：只调训练时长、验证集划分、初始化和正则这些"被忽略的因素"，就在 DomainBed 上**超过所有 SOTA 方法**，ResNet-50 上 +5%、ViT-B/16 上 +15%。
- **Rosenfeld et al. 2021**（理论）："Invariant Risk Minimization and its alternatives fundamentally do not improve over standard ERM."
- [On the Limitations of General Purpose DG Methods](http://arxiv.org/pdf/2202.00563) 给出解释：各种 DG 方法的效果差异本质上只是**在经验风险与模型复杂度之间选了不同的权衡点**，结论是"直接做带 leave-one-domain-out 交叉验证的正则化 ERM"就够了。

**这条对我们特别刺耳**：`docs/RESULTS_TRUTH.md` §5 显示，换训练配方在 ATCNet 上值 **2.4pp**，而对抗训练目前是 **−7pp**。我们已经在无意中复现了"配方 > 方法"这个结论。

### 2.2 关键分野：covariate shift vs posterior drift

[Domain Generalization Under Posterior Drift](https://doi.org/10.48550/arxiv.2510.04441)（2025-10）给出了判断该不该用 invariance 的判据：

| | 定义 | 正确做法 |
|:---|:---|:---|
| **covariate shift** | `p(X)` 随域变，`p(Y\|X)` **不变**——存在一个对所有域都好的分类器 | 学 domain-**invariant** 表征（DANN / CORAL / IRM）。但论文证明此时 domain 信息**没有决策论收益**（Corollary 1），ERM 已接近最优 |
| **posterior drift** | `p(Y\|X)` **随域改变** | pooling ERM **不够**。用 domain-**informed** ERM（把域信息喂给模型），收益有下界保证 `≥ γε/2`（Proposition 2） |

论文的核心论断是：**"ERM 难以被打败"这个结论主要来自视觉基准，而视觉基准基本都是 covariate shift。** 在 posterior drift 场景（论文举的例子是 NLP 标注者主观性——同一句话不同标注者给不同标签），结论反过来。

**这对我们是方向性的**：DANN 类方法的前提是"被试身份是需要清除的干扰变量"。如果 EEG 跨被试实际是 posterior drift 主导，那么清除被试信息就是**清除决策所需的信息**——不是效果有限，是方向错了。

### 2.3 EEG 跨被试的方法谱系

[Cross-subject generalization for EEG decoding: a survey](https://iopscience.iop.org/article/10.1088/2516-1091/ae65f0)（IOPscience 2026）的分类：

| 族系 | 机制 | 对我们的适配性 |
|:---|:---|:---|
| Feature alignment | 矩匹配 / 几何对齐 | 需要目标域数据，LOSO 下不适用 |
| **Adversarial（DANN/CDAN）** | minimax 骗过被试判别器 | 我们现在做的。**CDAN 值得试**——它把判别器条件在类别预测上，对齐 `p(z\|y)` 而非只是 `p(z)` |
| **Feature disentanglement** | 显式分解成 task code / subject code | FD-ARL 属于这一族。比纯 DANN 多**重建约束**，不强制丢弃被试信息，只是把它隔离——**在 posterior drift 下比纯 invariance 更稳妥** |
| Contrastive | 用 subject ID 构造正负样本对 | 中等 |
| Meta-learning | 每个被试当一个 task，episodic 训练 | 值得关注 |
| Invariant / causal | 找跨环境稳定的因果机制 | 理论好看，实践上属于 §2.1 打不过 ERM 的那一批 |

综述最后一节专门讨论 **"the structural value of subject identity"**，明确指出 subject ID 应该从"数据集索引"升格为"核心算法信号"——**这和 posterior drift 的结论方向一致：利用，而不是清除。**

### 2.4 具体候选（按性价比排序）

1. **CDAN（条件对抗）**——改动极小（判别器输入从 `z` 换成 `z ⊗ softmax(logits)`），直接对齐条件分布。是纯 DANN 到 posterior drift 之间最短的一步。
2. **FD-ARL 式解耦 + 重建**——学长自己的方法，隔离而非丢弃被试信息。
3. **[EEG-DG](https://arxiv.org/pdf/2311.05415)**——同时优化边缘和条件分布，有开源代码，BCI-IV-2a 上 81.79%。
4. **源被试筛选**（[BFM + Cauchy-Schwarz](https://ar5iv.labs.arxiv.org/html/2507.21037)）——不是所有源被试都该等权参与。我们的 sub-011 几乎肯定是负迁移源。这个思路对我们**特别对症**且实现便宜。
5. **domain-informed 而非 domain-invariant**——最激进也最符合理论的方向，但 LOSO 下测试被试没有标签，需要用无标签目标数据构造 domain 表征。

## 3. 任务 4：第一性原理分析

### 3.1 跨被试到底难在哪：让数据说话

| 量 | 数值 |
|:---|---:|
| 被试间极差（跨模型均值） | **50.1pp**（sub-011 37.0% → sub-007 87.1%） |
| 模型间极差（6 个模型） | **6.2pp** |
| 被试方差 / 模型方差 | **45.4×** |
| 换训练配方的影响（ATCNet） | 2.4pp |
| 换 val_mode 的影响 | 0.5pp |
| 对抗训练的影响（S4ERP） | +2.9pp |
| 对抗训练的影响（ATCNet，初步 5/11 折） | **−7.0pp** |

**所有方法层面的旋钮加起来都在 ±7pp 以内，而被试差异是 50pp。** 我们一直在 6pp 的空间里精雕细琢。

### 3.2 杠杆在哪

| 假想改进 | ATCNet 均值 | 增量 |
|:---|---:|---:|
| 现状 | 70.85% | — |
| 只把 sub-011 从 37% 修到 70% | 73.85% | **+3.00pp** |
| 再把 sub-006 从 56% 修到 70% | 75.08% | **+4.23pp** |
| 对比：全部 6 个模型之间的总极差 | | 6.16pp |

**修好一个被试 = 半个模型选择空间。** 修好两个 = 70%。

### 3.3 三个诊断问题

**Q1：sub-011 是"信号没有"还是"迁移失败"？**

这是整条路线的分水岭，而**我们没有数据能回答它**——仓库里没有任何 WBCIC-SHU 3 分类的被试内结果。
已提交实验 `wbci_3c_within_ceiling_v1`（SLURM 45973）：被试内 5 折交叉验证，同人同 session，完全没有域漂移，是可解码性的最紧上界。

- 若 sub-011 被试内也只有 ~40% → **信号质量问题**（BCI illiteracy）。任何域自适应都救不了，应该转向"识别并标记不可解码被试"（可靠性估计 / 拒识），而不是继续调对齐。
- 若被试内 ~80% → **真的是迁移失败**，那 50pp 里有很大一块是可攻的，值得投入。

**Q2：EEG 跨被试是 covariate shift 还是 posterior drift？**

支持 posterior drift 的证据：
- 不同被试的运动想象策略不同（动觉 vs 视觉想象），皮层折叠差异导致同一心理活动的头皮投影不同。**同一个 X 在不同被试身上可能对应不同的 Y** ——这就是 posterior drift 的定义。
- 强制不变性（ATCNet-Adv）在强骨干上**损失 7pp**，这正是 posterior drift 下 invariance 类方法的预期表现。
- 综述明确主张 subject ID 有"结构价值"，应利用而非清除。

支持 covariate shift 的证据：
- 电极阻抗、头型、基线偏移这些确实是纯粹的 `p(X)` 差异。
- S4ERP-Adv 拿到了 +2.9pp（但见下）。

**我的判断：两者都有，且 S4ERP 上的 +2.9pp 很可能不是"对抗有效"的证据。** S4ERP 过拟合极严重（gap +32.7pp），对抗项在那里主要起的是**通用正则**作用，而不是真的学到了被试不变性——证据是 λ 从 0.1 扫到 2.0 结果完全没差别（67.2%~67.8%），如果机制真是不变性学习，对抗强度不可能不敏感。换到不怎么过拟合的 ATCNet（gap +22.1pp）上，正则的边际价值消失，invariance 的副作用就暴露成 −7pp。

`adv_821recipe_3c_v1`（SLURM 45821）正在验证这一点：如果 S4ERP-Adv 在论文配方（更强的隐式正则，S4ERP 因此从 64.68% 涨到 68.26%）下增益消失，就坐实"对抗 = 正则替代品"。

**Q3：8 个源域够做域对抗吗？**

DANN 的理论保证依赖域数量足够多以估计域分布。我们每折只有 **8 个训练被试**，判别器要做 11 类（现实现里是 8 类）分类。这个样本量下判别器很容易记住个体而不是学到分布差异，梯度信号偏噪声。这也和 λ 扫描无差异的观察吻合。

### 3.4 结论

1. **当前的技术路线（domain-invariant adversarial）在理论和数据上都缺乏支撑。** 理论上它假设 covariate shift；数据上它在最强骨干上损失 7pp，在弱骨干上的收益无法与"通用正则"区分。
2. **真正的杠杆在被试层面，不在模型层面**（50pp vs 6pp）。
3. **下一个决策点是 45973 的被试内天花板结果**，它决定这 50pp 里有多少是可攻的。
